Load dari API

Gunakan ini saat ada update BUMO atau KC Area. Paste bearer token yang masih aktif, lalu sistem menyimpan hasilnya ke database lokal.

Setelah berhasil, user cukup refresh halaman form supaya cache browser memakai versi data terbaru.

Upload Master Data

Pilih jenis data, lalu upload Excel, CSV, atau JSON response API. Data dengan key yang sama akan di-update.

Header BUMO wajib: name. JSON BUMO boleh memakai format API data.data seperti hasil endpoint BUMO. Header KC Area wajib: area_id dan area_name. Header opsional untuk keduanya: is_active atau status, isi dengan 1/0, aktif/nonaktif, ya/tidak.
